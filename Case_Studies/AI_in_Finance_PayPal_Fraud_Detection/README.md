# AI in Finance – PayPal Fraud Detection

## Overview
This project explores how PayPal uses machine learning to detect fraudulent transactions in real time and protect users from financial threats.

## Key Areas
- Fraud detection systems  
- Behavioral pattern analysis  
- Risk scoring models  
- Real-time transaction monitoring  

## What I Learned
- Anomaly detection techniques  
- Machine learning in finance  
- How AI scales across millions of transactions  

## Challenges
- False positives blocking real users  
- Bias in training data  
- Difficulty explaining AI decisions
